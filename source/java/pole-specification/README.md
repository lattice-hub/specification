# Pole Specification Java

Pole Specification 的官方 Java Protobuf Message 与 gRPC Stub 包。

```xml
<dependency>
    <groupId>io.github.lattice-hub</groupId>
    <artifactId>pole-specification</artifactId>
    <version>0.1.0-ALPHA.43</version>
</dependency>
```

Maven 构建从仓库根目录 `api/` 收集全部权威 Proto，不提交生成代码。
